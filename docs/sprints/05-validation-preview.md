# Sprint 05: Validation and preview

## Outcome

Authors see publish checks, configure required fields, and switch responsive preview widths. Respondents receive linked, field-specific errors and a valid-preview confirmation. The product is ready for its first demo release.

## Evidence

Validation tests cover authoring conflicts and a respondent truth table. Component tests prove linked summaries, invalid semantics, required editing, and preview mode state. The demo script exercises the complete author flow.

## Review prompts

- Why are authoring and response failures different contracts?
- What does client validation improve but not secure?
- Why does the error summary link to controls?
