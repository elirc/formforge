# FormForge v0.5 demo

1. Run `pnpm dev` and open `http://127.0.0.1:5173`.
2. Use the skip link and primary navigation to inspect the semantic shell.
3. In the authoring studio, add an email field and rename it “Follow-up email.”
4. Duplicate the field, delete the copy, then move the original upward with keyboard controls.
5. Toggle required response and switch between desktop and mobile preview widths.
6. Submit the empty preview. Follow an error-summary link to an invalid field.
7. Complete the required values and observe the valid-preview status.
8. Run `pnpm gate` and explain what each independent evidence layer proves.

The demo uses in-memory React state. Persistence, publishing, and real public submission are explicitly later milestones.
