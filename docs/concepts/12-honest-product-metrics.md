# Concept 12: Honest product metrics

A metric is incomplete without a numerator, denominator, time window, and missing-data policy. “75% completion” is meaningful here because it says 18 completed journeys out of 24 recorded starts.

Medians resist extreme durations better than means, but excluding invalid timestamps must be visible in the contract. Zero starts means there is no observed rate; the UI chooses an explicit empty state rather than displaying an impressive but meaningless chart.

Charts are summaries, not the data itself. FormForge’s bars are decorative and each has an adjacent semantic table with exact count and rate values.
