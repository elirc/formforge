# FormForge extended engineering course

This completed source-grounded expansion of the [existing Astra course](../README.md) contains forty-eight chapters, fifteen separate review guides, and two isolated executable models. Chapters teach current behavior separately from proposed features. No application changes are required to read or complete the prediction exercises.

Begin with basic TypeScript objects, promises, React effects, and HTTP request/response vocabulary. If those are unfamiliar, use the existing [prerequisites](../00-PREREQS.md). Keep a prediction notebook and attempt exercises before opening answers. Use synthetic forms and your own answer files; preserve the application and existing learner work.

## Opening route

1. [Three independent identities](01-follow-three-independent-identities.md): draft, snapshot, and response attempt.
2. [Parsing and publication readiness](02-parse-validate-and-publish.md): shape, semantics, rejection order.
3. [Conditional drafts and defensive copies](03-conditional-drafts-and-defensive-copies.md): version preconditions and ownership.
4. [Autosave's local sequence and server version](04-autosave-has-two-clocks.md): deterministic schedules and honest status.
5. [Publication and retry incidents](05-publication-and-retry-incidents.md): address history and duplicate payload policy.
6. [Independent integration capstone](06-capstone-connect-the-real-boundaries.md): adapter, editor lifetime, evidence, and rubric.

Separate answers: [identity and validation](review-01-identity-and-validation.md), then [scheduling and integration](review-02-scheduling-and-integration.md).

## Course scope and evidence

The continuation covers schema and answer semantics, builder transformations, rules and flow, response analysis, publication storage design, operational evidence, API integration, accessibility, and independent capstones. Durable adapters, offline ledgers, authorization, outboxes, and export jobs are explicitly proposed designs, not completed application features. The organizer report records measured instructional prose excluding this README and fenced code, along with the bounded model checks and documentation audit.
